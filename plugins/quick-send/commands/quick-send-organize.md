---

把本对话内容或用户指定主题整理成常用语并入库。严格走五步，顺序不可乱：

1. **查重**：调用 quick-send 的 `list_snippets`，掌握现有条目（标题+分类），避免重复整理；
2. **拟草稿**：整理 3–10 条（用户另有指定则从其指定）。标准——
   标题 = 动宾短语、≤20 字；正文 = 可直接整句发送的完整指令，合适的时机用
   `{{date}}` / `{{time}}` / `{{datetime}}` / `{{workspace}}` 占位符（`{{clipboard}}` 仅
   ZCode 侧展开）；分类优先归入现有分类，确需新建才新起；
3. **等确认**：以表格列出草稿（标题｜分类｜正文摘要），问用户「确认写入哪几条？」
   **未经用户确认不得调用写入**；
4. **写入**：确认后用 `bulk_add_snippets` 一次写入（完全重复项会被自动跳过，
   逐条回报 added / skippedDuplicates / failed）；
5. **汇报**：报新增/跳过/失败清单，提醒可用 `/quick-send` 打开面板查看调整。
