## 只改文案，不动一行逻辑

0.3.0 把界面拆成了「浮层插入 + 侧边栏管理页维护」，但有 3 处说明文字还在讲旧的
单面板形态。这版把它们对齐。

**功能与 0.3.0 完全一致，测试仍为 112 项全过。已经装好 0.3.0 的话可以不升。**

### 修了什么

| 文件 | 原来 | 改成 |
|---|---|---|
| **`package.json`** `description` | 「输入框**上方**的常用语**面板**，一键填入草稿」 | 「**浮层**一键插到光标处，**侧边栏管理页**负责增删改与排序」 |
| **`README.md`** 首段 | 「输入框旁的常用语**浮层面板**」 | 「浮层一键插入 + **侧边栏管理页**负责维护」 |
| **`src/client.js`** 顶部注释 | 只列 2 个槽位 | 补齐 4 个槽位（含 `sidebar.panellist` + `main`），并注明 **`id` 必须等于 `key`** |

**`description` 是这次发版的主因**——它会显示在 npm 搜索页和插件市场里，
是陌生人看到的第一句话。0.3.0 发布时它还写着「输入框上方的面板」，与实际的
两个界面不符。

### 顺带补的文档

`README.md` 变更记录补了 0.3.1 条目，明确说明「与 0.3.0 功能一致、可不升」，
避免已升级的用户困惑。
